# 愿景与五年路线（草案 v1）

## 使命
发现消费领域的潜在机会，做出未来 5 年在 AI 应用上领先、满足真实需求、拓展场景想象力的产品。

## 产品线
| 产品 | 定位 | 对应 Agent | 当前状态 |
|---|---|---|---|
| **goforu** | 旅行规划与研学产品：户外研学导师（主线）+ 东南亚旅行规划版 | 户外研学导师 | 主产品，开发中 |
| **moonrain** | 视听情绪检测、回应与陪伴的"朋友" | 情绪陪伴朋友 | Phase 3，无远程备份 |
| **fenci** | 击剑视频教练 | 击剑视频教练 | 停滞（4 月后未动） |
| **fgame** | 化学学习游戏 | — | 原型 |
| **per** | 待确认，将合并进本总部 | — | 在 `D:\codex\per`，尚未接入 |

## 阶段
| 阶段 | 时间 | 核心结果 |
|---|---|---|
| P0 基建期 | 2026 Q4 | 总部和 5 人团队上岗；所有活跃项目上 GitHub 私有仓库；每日情报和每日站会自动运行 |
| P1 验证期 | 2027 H1 | goforu 研学版找 20 位真实用户试用；moonrain 定下安全边界并做内测 |
| P2 产品化 | 2027 H2 | 第一个付费产品上线；硬件原型（开发板 + 外壳） |
| P3 规模化 | 2028 | 专业小模型 v1（大模型蒸馏 + LoRA + 知识库）；场景数据形成飞轮 |
| P4 平台化 | 2029–2030 | 研学、陪伴、运动共用一个 Agent 能力底座 |
| P5 领先期 | 2031 | 在细分消费场景里成为 AI 应用标杆 |

## 原则
1. 一次只全力推一个主产品，现在是 goforu。
2. 不从零训练基础模型：用大模型做老师，训练专业小模型，再加知识库。
3. 真正的壁垒是场景数据和评测集。
4. 硬件先用开发板验证，确认用户真的需要（PMF）之前不自研电路板。
