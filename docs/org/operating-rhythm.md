| 随时 | — | Scout | 和创始人讨论想法 → 创意卡 | `ops/ideas/` |

## 监督机制（Chief）
1. 每份产出按模板检查：有没有来源、有没有结论、有没有下一步、有没有负责人和日期。
2. 不合格的打回给原岗位，并在站会摘要里记一笔。
3. 连续两次打回，或者节点逾期超过 3 天，在周复盘里升级给创始人。

## 自动化方式（本地优先）
- 总部仓库和 per 的自动化脚本都在创始人的 Windows 电脑上运行。
- 定时任务用 **Windows 任务计划程序**，替代 per 原来在 macOS 上用的 `.plist`。
- 模型调用统一走 per 的 `llm_client.py`，不绑定某一家平台。
- 密钥只放在本机的 `.env` 文件里，永远不提交。
- 项目进度直接读本机的 git 仓库，本地项目也能巡检。
- 以后上云：可以重新打开已暂停的云端定时任务，也可以改用 GitHub Actions。
